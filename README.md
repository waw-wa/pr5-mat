# Практична робота № 9-10: Неперервні випадкові величини, закони розподілу та статистичне моделювання в аналізі продуктивності ПЗ

Цей репозиторій містить програмну реалізацію, графіки та звіт для практичної роботи № 9-10 з дисципліни «Теорія ймовірностей та математична статистика».

---

## Загальна інформація

* **Дисципліна:** Теорія ймовірностей та математична статистика
* **Тема:** Неперервні випадкові величини, закони розподілу та статистичне моделювання в аналізі продуктивності ПЗ
* **Варіанти завдань:**
  * **Блок 1:** Загальне завдання (Програмна перевірка Центральної Граничної Теореми)
  * **Блок 2:** Варіант 2 (MTBF сервера)
  * **Блок 3:** Загальне завдання (Перцентильний аналіз затримок ПЗ / Latency Tail Analysis)
  * **Блок 4:** Варіант 8 (Тривалість сесії користувача)

---
